# YouTube to MP3 Converter

This project allows users to convert YouTube videos into MP3 audio files quickly and easily. 

## Screencapture

<img src="./yt-to-mp3-SS.png" alt="Screencapture of application" width="400" />

## Features

- Convert any YouTube video to MP3 format.
- High-quality audio extraction.
- Simple and user-friendly interface.

## Installation

To use this project, clone the repository and install the required dependencies:

```bash
git clone https://github.com/Allenreinoso28/youtube-to-mp3.git
cd youtube-to-mp3
```
## Requirements

Python 3.x
YouTube API key

## Dependencies
Install the required packages:

```bash
pip install -r requirements.txt
```

## Usage
Run the application:

```bash
python main.py
```
Enter the URL of the YouTube video you wish to convert.
